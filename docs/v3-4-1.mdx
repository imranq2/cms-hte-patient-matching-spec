## What changed

### Removed

- **Rule 29 (First Name\* + Last Name\* + Phone Number + ZIP) is removed from Table 2** ([Proposal v3.4.1](https://github.com/imranq2/cms-hte-patient-matching-spec/issues/7)).
  - The rule has no date of birth, so it matched a parent and child who share a name, phone number, and ZIP code.
  - Its ID is retired and not reused. Rules 30 and above are not renumbered, so IDs run 01 to 30 with 29 absent. [Table 2](/docs/table-2-category-1-rules) shows rule 29 struck through.
  - The Category 1 count changes from 30 to 29. The Category 2 count of 8 is unchanged.

### Consequences the proposal notes

- Rule 29 was the only approved rule that could evaluate provider data of the NPPES shape, so provider matching needs a separate follow-up.
- A patient query with name, phone, and ZIP but no date of birth no longer matches under Table 2.

### Everything else

Unchanged from [v3.4.0](/docs/v3-4-0), except the Category 1 count in the [Executive Summary](/docs/summary-and-purpose), the version, effective date and comment period in [Document Control](/docs/document-control-and-comments), and the [downloads](/docs/table-2-downloads), which no longer include rule 29. Pages on this site show "Specification v3.4.1" in their headers for that reason.
